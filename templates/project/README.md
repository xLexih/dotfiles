## Set up a clone

1. Run `direnv allow`, or run `nix develop`.
2. Run `just setup`. This installs the git hooks, selects your key and decrypts the private files.

To show all commands, run `just`.

## Private files

Git does not keep these files as plain text: `.env*`, `*.private` and `*.private.*`. Files that end in `.example` are not private.

When you commit, a git hook encrypts the changed private files into `.encrypted/`. When you check out or pull, a git hook decrypts them. Git refuses a commit with nothing staged, so if only private files changed, run `just private-encrypt` before you commit.

```bash
just private-status
just private-add-key ~/.ssh/id_ed25519          # give a key access, then commit
just private-remove config.private.yaml
```

To remove the access of a key:

1. Remove the line of the key from `.encrypted/recipients`.
2. Run `just private-reencrypt`.
3. Commit.
4. Change the secrets that the key could read.
